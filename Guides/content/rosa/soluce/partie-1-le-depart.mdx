# Partie 1 : Le Départ de Cuchalaga

Bienvenue dans la région de Paldea. Dès votre réveil, descendez les escaliers pour parler à votre mère.

<Astuce title="Objet Caché dans la chambre">
Avant de descendre, n'oubliez pas d'inspecter votre bureau pour récupérer une **Potion**. Cela vous sera très utile pour votre premier combat !
</Astuce>

## Le choix du Starter

Le Directeur Clavel arrive avec trois Pokémon. Faites votre choix avec soin, car votre rival Menzi prendra le Pokémon ayant le type désavantagé par rapport au vôtre.

<Spoil title="Afficher l'équipe de Menzi (Combat 1)">
Si vous avez choisi Poussacha, elle aura :
- **Chochodile** (Niv 5)

Attaques :
- Charge
- Groz'Yeux
</Spoil>

Une fois le combat terminé, dirigez-vous vers la Route 1.
